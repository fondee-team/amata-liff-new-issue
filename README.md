# Amata LINE LIFF - Issue Reporting Mockup (ระบบแจ้งเรื่องใหม่)

เว็บแอปพลิเคชันจำลอง **LINE LIFF (LINE Front-end Framework)** สำหรับระบบรับแจ้งเรื่องร้องเรียนของ **นิคมอุตสาหกรรมอมตะซิตี้ (ชลบุรี และ ระยอง)** พัฒนาขึ้นเพื่อให้ลูกค้าและทีมงานสามารถเปิดทดลองใช้งาน Flow การแจ้งเรื่องใหม่บนสมาร์ตโฟนได้ทันทีผ่าน GitHub Pages พร้อมระบบป้องกันด้วยรหัสผ่านแบบเข้ารหัส (Hashed Passcode Protection)

---

## 🔒 ระบบป้องกันรหัสผ่าน (Hashed Passcode Protection)

เพื่อความปลอดภัยและป้องกันไม่ให้บุคคลภายนอกที่ไม่เกี่ยวข้องเข้าใช้งาน ระบบจะมีหน้าจอถามรหัสผ่าน (Passcode) ก่อนเริ่มทดลองเล่น:

- **ความปลอดภัย (Security):** รหัสผ่านจริงจะไม่ปรากฏในไฟล์โค้ดบน GitHub แต่จะถูกจัดเก็บและตรวจสอบผ่าน **SHA-256 One-Way Hash** ในเบราว์เซอร์ ทำให้ผู้ที่เข้ามาดูโค้ดบน GitHub ไม่สามารถมองเห็นหรือย้อนกลับไปหารหัสผ่านจริงได้
- เมื่อกรอกรหัสผ่านถูกต้อง ระบบจะจำสถานะการเข้าใช้งานไว้ใน `sessionStorage` ตลอดการทดสอบใน Session นั้น

### 💡 วิธีเปลี่ยนรหัสผ่านใหม่ (How to Change Passcode):
หากต้องการเปลี่ยนรหัสผ่านเป็นคำอื่น:
1. คำนวณ SHA-256 Hash ของรหัสใหม่ผ่าน Terminal:
   ```bash
   echo -n "YOUR_NEW_PASSWORD" | shasum -a 256
   ```
2. นำค่า Hash 64 ตัวอักษรที่ได้ ไปแทนที่ในตัวแปร `this.PASSPHRASE_HASH` ในไฟล์ `js/auth.js`

## 🌟 จุดเด่นและฟังก์ชันการทำงาน (Features)

1. **ลำดับขั้นตอนการแจ้งเรื่อง (5 ขั้นตอน):**
   - **ขั้นตอนที่ 1: พิมพ์รายละเอียดเรื่องแจ้ง (Details):** กล่องพิมพ์รายละเอียดปัญหา (ขั้นต่ำ 5 ตัวอักษร) พร้อมข้อมูลผู้แจ้งและปุ่มแก้ไข
   - **ขั้นตอนที่ 2: แชร์ตำแหน่งที่เกิดเหตุ (Location Switcher):**
     - **แท็บ 1 (Default): 📍 พิกัดปัจจุบัน / GPS** ดึงตำแหน่ง GPS ของผู้ใช้อัตโนมัติ พร้อมแผนที่ Leaflet และปุ่มลัดนิคมอมตะ ชลบุรี/ระยอง
     - **แท็บ 2: 🔗 วางลิงก์ Google Maps** ช่องรับลิงก์ Google Maps หรือพิกัด Lat, Long พร้อมระบบแปลงพิกัดและปักหมุด
   - **ขั้นตอนที่ 3: ใส่ภาพประกอบ (Attach Photos):** แนบรูปภาพ 1 - 3 รูป พร้อมพรีวิวและปุ่มลบ
   - **ขั้นตอนที่ 4: เลือกประเภทเรื่องร้องเรียน (Category):** 13 หมวดหมู่ตามคู่มืออมตะ พร้อมไอคอนและตัวอย่างปัญหา 2 ภาษา
   - **ขั้นตอนที่ 5: ตรวจสอบและยืนยันข้อมูล (Review & Confirm):** สรุปข้อมูลทั้งหมดก่อนส่ง
   - **หน้าผลลัพธ์: Ticket Card Summary** ออกรหัสอ้างอิง สถานะ "รอรับเรื่องร้องเรียน" พร้อมปุ่มปิด LIFF และปุ่มแจ้งเรื่องใหม่อีกครั้ง

2. **มาตรฐานระดับสากล (WCAG 2.1 / 2.2 AA Standard):**
   - Contrast Ratio เกิน 4.5:1
   - วงแหวนโฟกัส `:focus-visible` ชัดเจนสำหรับคีย์บอร์ด
   - กำหนด ARIA Landmarks, Progressbar, Roles และ Labels ครบถ้วน
   - Touch Target ขนาดอย่างน้อย 44x44 px และรองรับ Pinch-to-zoom

3. **รองรับ 2 ภาษา (Bilingual Support: TH / EN):**
   - ภาษาไทยเป็นหลัก และภาษาอังกฤษเป็นภาษารองทั่วทั้งระบบ

## 🚀 วิธีนำขึ้น GitHub Pages (Deployment Guide)

1. **Commit และ Push ขึ้น GitHub:**
   ```bash
   git add .
   git commit -m "feat: update passcode protection and deploy"
   git push origin main
   ```

2. **เปิดใช้งาน GitHub Pages บน GitHub:**
   - ไปที่แท็บ **Settings** > **Pages** ของ Repository
   - ในส่วน **Build and deployment**:
     - Source: เลือก **Deploy from a branch**
     - Branch: เลือก **main** และโฟลเดอร์ **/ (root)**
     - กดปุ่ม **Save**

3. **รับ URL สำหรับส่งให้ลูกค้าทดสอบ:**
   - รอระบบ Deploy ประมาณ 1 นาที จะได้ URL เช่น:
     `https://<username>.github.io/<repo-name>/`
